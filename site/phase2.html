    METHODS & REPRODUCIBILITY

    Evidence stays attached.

    This aggregate view is a reading aid. Original immutable provenance and scientific review remain authoritative.

    Identity before deduplication

    File SHA, assay identity, observation identity, input identity and split group answer different questions. The same sequence under different conditions is not automatically a duplicate experiment.

    Splits before fitting

    Preserve official test splits where available. Label custom splits as RNA-Gym versions. Fit scalers, thresholds and hyperparameters on training data only; audit gene, family and structure-level leakage.

    Candidate is not admitted

    FILE_QC_PASS, SOURCE_VERIFIED, ASSAY_VERIFIED and SPLIT_QC_PASS are evidence stages. ADMISSION_CANDIDATE does not replace a real, auditable final approval.

    Public aggregates only

    Export requires explicit public-aggregate approval. Raw labels, hidden test labels, sample identity maps, private paths, credentials and reviewer records never belong in this website snapshot.

    Readout-specific evaluation

    Keep RSS, MRL, TE, half-life, splicing and eCLIP distinct. Do not add unlike Spearman, F1, AUROC or structure metrics into one score. Report task coverage and uncertainty.

    No implicit compute

    Website generation runs no training, inference, downloads or deployment. Cheap smoke tests precede experiments; GPU training needs separate authorization.

    Local rebuild and publication boundary

    Use tools/build_phase2_site.py with --audit, a new --output directory and --approve-public-aggregates. Validate with --dry-run first. The builder refuses to replace a different snapshot; use a new versioned directory. A separate reviewed integration step copies approved aggregates into the served Phase 2 target.
