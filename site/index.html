METHODS / MODALITY TRACKS

公平输入，分轨评测。

纯序列、paired RNA、RNA / 结构 / 配体条件以及生成设计独立建榜。RSS、MRL 和 TE 是不同 readout，不合并标签。

IDENTITY

观察不等于序列

只有同一实验观测真正重复才合并；同一序列的不同 cell、probe、replicate、timepoint 和 readout 保留。U / T 转换须记录。

SPLIT

先冻结，再评估

优先原作者固定 test。WT / backbone、同源家族、PDB-chain、miRNA / RBP、配体 scaffold 和原始 read molecule 分组防泄露。

TRAIN-ONLY FITTING

测试集不能调参

scaler、阈值、HPO 只用训练 folds。held-out / test 不参与预训练或表征缓存微调；保留 overlap report 和 exclusion log。

AGGREGATION

不直接相加异质指标

fold → task → assay → source family → domain。预定义模态权重；报告 N/A、覆盖率、bootstrap 和权重敏感性，再讨论排名。

2D、3D、ligand、Nanopore 各自需要专用 QC。exact tabular QC 通过不等于完整科学 QC，更不等于最终准入。

BASELINES / DECLARED, NOT EXECUTED

先证明任务可评，再谈模型高低。

每个任务卡保留 registry 的 input、loss、metric、低信息对照、经典模型和随机初始化 DL 声明。名称只是候选配置，不表示 baseline 已运行；模态与 label 不符先 HOLD。

CONTROL

低信息对照

检验标签、类别频率、长度或构件等 shortcut；miRNA-only shortcut 不可代替真实 assay。

CLASSICAL

经典特征 / 领域工具

使用与任务模态一致的输入和合法工具。原始单位、标签方向和损失函数不可静默改写。

SCRATCH

随机初始化 DL

独立于 FM 预训练收益，仅先设计 prepare / run / evaluate 接口与 toy smoke。本轮不调度训练。

DATA GOVERNANCE / PUBLIC BY DESIGN

公开边界，也是方法的一部分。

只公开可公开的索引

本站只含来源链接、任务声明和汇总证据；不含内部 UTR 数据、原始测量、10-fold splits、私有权重、用户身份、原审计 Markdown 或 XLS。

权限不明就 HOLD

公开仓库不等于数据可重分发。HOLD_AUTH / HOLD_LICENSE / HOLD_RELEASE / HOLD_SOURCE 仅阻断具体资产，不绕过登录、不获取隐藏标签。

从快照到可追溯变更

上游变更新建版本，不用同名文件覆盖旧字节。保留 immutable provenance、raw SHA256、alias 和 split manifest；自动化不代签人工批准。

网页展示的 release / index verification、候选链接与 HASHED / REVIEW_READY 分开标记。包级文件不能证明该包内所有任务的 assay 身份或样本 N。

CONTRIBUTE / CITATION & REPRODUCIBILITY

补一条证据，而不是补一个分数。

提交来源修正

以 task_id 和来源族为入口，提供公开的原论文 / accession、版本、权利证据与实际文件 SHA256。请勿提交标签、受限原始文件、token 或权重。

先核实 assay alias 和实验条件；未知项保留 unknown。后续发布应通过受审查 PR，不会从本地预览自动上传。
